#Cache Coherence Traffic Analysis (CCTA)
-------------------------------------------------------------------------------------------------------------
A gem5-based platform that captures, analyzes, and exports realistic cache-coherence traffic generated during full-system application execution. It enables researchers to study coherence communication across different workloads, cache hierarchies, and coherence protocols, and provides reusable traffic traces and statistics for downstream NoC and architecture studies.
